HOW TO PUBLISH (GitHub Pages, free)
1. Sign in at github.com as neutron-96.
2. New repository, name it exactly: neutron-96.github.io  (Public). Create.
3. Click "uploading an existing file". Drag in EVERYTHING from this folder
   (index.html, cv.pdf, and the assets folder). Commit changes.
4. Settings > Pages > Source: Deploy from a branch > main > / (root) > Save.
5. Wait 1-2 minutes, then open https://neutron-96.github.io

UPDATING YOUR CV LATER
Upload your new CV, named exactly cv.pdf, to the repository (Add file > Upload files).
It replaces the old one; the site updates in about a minute.
